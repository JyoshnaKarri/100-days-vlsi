Day 1

Binary Number Systems & Conversions

⏱️ Time 2.5 hours
📊 Difficulty Beginner
🔧 Tech Digital Logic · Number Systems
📘 Concept Summary
Mastered binary, decimal, and hexadecimal conversions. Learned binary addition, subtraction, and 1's/2's complement — the absolute foundation of every digital system.
💻 Code Example
// Decimal → Binary (47) 47 / 2 = 23 rem 1 (LSB) 23 / 2 = 11 rem 1 11 / 2 = 5 rem 1 5 / 2 = 2 rem 1 2 / 2 = 1 rem 0 1 / 2 = 0 rem 1 (MSB) → 101111 // 2's Complement of 1010 1's complement: 0101 Add 1: 0110 → 2's complement // Binary addition: 1011 + 0111 1011 + 0111 ------ 10010 (carry out)
🌍 Real-World Applications
  • Memory addressing — every byte in RAM is accessed via binary/hex addresses.
  • 2's complement is the standard for signed integer arithmetic in CPUs (x86, ARM, RISC-V).
  • Hex is used in debugging, waveform viewers, and machine code disassembly.
  • Binary addition/subtraction circuits form the ALU inside every processor.
Day 2

Boolean Algebra & DeMorgan's Laws

⏱️ Time 3 hours
📊 Difficulty Beginner+
🔧 Tech Boolean Logic
📘 Concept Summary
Applied all 9 Boolean laws to simplify expressions, and mastered DeMorgan's theorems: (X·Y)' = X' + Y' and (X+Y)' = X'·Y'. Golden rule: break the line, change the sign.
💻 Code Example
// Simplify: (A + B)' + A·B Step 1: DeMorgan → A'·B' + A·B Step 2: Distributive / consensus → A'·B' + A·B // final simplified form (XOR-like) F = A'·B' + A·B
🌍 Real-World Applications
  • Logic optimization in synthesis tools (Design Compiler, Yosys) uses DeMorgan to reduce gate count.
  • CMOS NAND/NOR mapping heavily relies on Boolean identities to minimize transistors.
  • FSM next-state logic is simplified with K-maps and Boolean laws before RTL coding.
