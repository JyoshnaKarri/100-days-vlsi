Boolean Algebra & DeMorgan's Laws

📖 Definition
Boolean algebra is a branch of mathematics that works with only two values — 0 (false) and 1 (true). It defines the rules for combining these values using operators like AND (·), OR (+), and NOT ('). Every digital circuit in existence is an implementation of Boolean algebra.
📘 Concept Summary
Learned 9 Boolean laws and DeMorgan's two theorems. Applied them to simplify complex expressions step by step. Golden rule: break the line, change the sign.
🧮 The 9 Boolean Laws
LawAND FormOR Form
AnnulmentX · 0 = 0X + 1 = 1
IdentityX · 1 = XX + 0 = X
IdempotentX · X = XX + X = X
ComplementX · X' = 0X + X' = 1
Involution(X')' = X
CommutativeX · Y = Y · XX + Y = Y + X
AssociativeX·(Y·Z) = (X·Y)·ZX+(Y+Z) = (X+Y)+Z
DistributiveX·(Y+Z) = X·Y + X·ZX + (Y·Z) = (X+Y)·(X+Z)
AbsorptionX·(X+Y) = XX + (X·Y) = X
🧮 DeMorgan's Theorems
TheoremEquation
Theorem 1(X · Y)' = X' + Y'
Theorem 2(X + Y)' = X' · Y'
Golden Rule: Break the line (the NOT bar), change the sign (· becomes +, + becomes ·).
🔍 Worked Example — Simplification
Simplify: (A + B)' + A·B Step 1: Apply DeMorgan Theorem 2 to (A + B)' → A' · B' Expression now: A'·B' + A·B Step 2: This is the canonical XNOR form. Cannot be simplified further using basic laws — it is already minimal. Final: F = A'·B' + A·B (= XNOR)
DeMorgan Application — NAND from OR
Original gate: A NAND B = (A · B)' Apply DeMorgan Theorem 1: (A · B)' = A' + B' Result: A NAND B == A' OR B' So a NAND gate can be built from: • Two inverters (for A' and B') • One OR gate
💻 Verilog Code
// Day 2 — Boolean algebra is applied inside every Verilog module. // Example: NAND gate implementing (A·B)' module nand_gate ( input a, b, output y ); assign y = ~(a & b); // DeMorgan: equivalent to ~a | ~b endmodule // Testbench module nand_gate_tb; reg a, b; wire y; nand_gate uut (a, b, y); initial begin $dumpfile("nand.vcd"); $dumpvars; a=0; b=0; #10; a=0; b=1; #10; a=1; b=0; #10; a=1; b=1; #10; $finish; end endmodule
🌍 Real‑World Applications
  • Synthesis tools (Design Compiler, Yosys) use Boolean laws to minimize gate count and reduce chip area.
  • CMOS NAND/NOR mapping relies on DeMorgan to translate logic into transistor-level circuits.
  • FSM next-state logic is simplified with K‑maps and Boolean laws before being written in RTL.
  • Kernel-level optimization — every time you write assign y = ~a | ~b; you're using DeMorgan in practice.

Day 3

NAND & NOR as Universal Gates

📖 Definition
A universal gate is a gate that can implement any other logic gate (NOT, AND, OR, XOR, XNOR, etc.) using only copies of itself. The two universal gates are NAND and NOR.
📘 Concept Summary
Built NOT, AND, OR using only NAND. Built NOT, OR, AND using only NOR. Compared CMOS implementations — NAND is faster than NOR (electrons vs holes physics). Both consume 4 transistors in CMOS.
🧮 Building Gates from NAND
GateNAND Implementation
NOTNAND(A, A)
ANDNAND(NAND(A,B), NAND(A,B))
ORNAND(NAND(A,A), NAND(B,B))
🧮 Building Gates from NOR
GateNOR Implementation
NOTNOR(A, A)
ORNOR(NOR(A,B), NOR(A,B))
ANDNOR(NOR(A,A), NOR(B,B))
🔍 CMOS Implementation
GatePMOSNMOSTransistors
NAND2ParallelSeries4
NOR2SeriesParallel4
AND2NAND + Inverter—6
OR2NOR + Inverter—6
Why NAND is faster: NMOS transistors (which are in series in NOR2) have higher resistance than PMOS. Series NMOS in NOR → slower pull-down. NAND has series NMOS in the pull-down path but parallel PMOS in the pull-up — a better balance. Electrons (NMOS) are ~2–3× more mobile than holes (PMOS), so NAND > NOR.
💻 Verilog — Building AND/OR/NOT from NAND
// NAND primitive module nand2 (input a, b, output y); assign y = ~(a & b); endmodule // NOT from NAND module not_from_nand (input a, output y); nand2 u1 (a, a, y); endmodule // AND from NAND (NAND + inverter) module and_from_nand (input a, b, output y); wire n; nand2 u1 (a, b, n); nand2 u2 (n, n, y); // inverter endmodule // OR from NAND (DeMorgan) module or_from_nand (input a, b, output y); wire na, nb; nand2 u1 (a, a, na); // ~a nand2 u2 (b, b, nb); // ~b nand2 u3 (na, nb, y); // ~(~a · ~b) = a + b endmodule
🌍 Real‑World Applications
  • ASIC standard cell libraries are dominated by NAND and NOR cells because of their density and speed.
  • 7400 series ICs — the quad 2-input NAND was the first mass-produced logic chip, used in Apollo missions and early PCs.
  • NAND flash — the storage technology inside every SSD, USB drive, and phone is named after its NAND-like charge-trap structure.
  • FPGA lookup tables (LUTs) are built from small muxes, but the routing fabric is dominated by NAND-like cells.

Carry Look‑ahead Adder (CLA)

📖 Definition
A Carry Look‑ahead Adder computes all carry bits in parallel using two signals — Generate (G) and Propagate (P). This eliminates the sequential carry chain of a ripple adder, giving constant delay regardless of bit width.
📘 Concept Summary
Learned the generate/propagate formulation, derived carry equations for all bits, and compared delay: CLA = 4 gate delays (constant) vs RCA = 2N gate delays. For 32 bits, CLA is ~16× faster.
🧮 Generate & Propagate
SignalFormulaMeaning
GiGi = Ai · BiBit generates a carry internally
PiPi = Ai ⊕ BiBit passes a carry from below

Asynchronous FIFO — The Right Way to Cross Clock Domains

📖 Definition
An asynchronous FIFO transfers data between two clock domains using Gray-coded pointers. Because only one bit changes per count, the pointer is safe to synchronise — no metastability, no data corruption.
📘 Concept Summary
Solved the classic interview question: "How do you send data from 100 MHz to 40 MHz?" — with a Gray-coded asynchronous FIFO. Verified waveform: writes on fast clock, reads on slow clock, no glitches.
🧮 How It Works
1. Write pointer (binary) → Gray → send to read clock domain via 2-FF synchroniser 2. Read pointer (binary) → Gray → send to write clock domain via 2-FF synchroniser 3. Full flag: compare write pointer with synchronised read pointer 4. Empty flag: compare read pointer with synchronised write pointer 5. Dual-port memory: write on wclk, read on rclk
💻 Verilog — Asynchronous FIFO
module async_fifo #(parameter DEPTH=8, WIDTH=8) ( input wclk, wrst, rclk, rrst, input wr_en, rd_en, input [WIDTH-1:0] din, output reg [WIDTH-1:0] dout, output full, empty ); localparam ADDR_WIDTH = $clog2(DEPTH); reg [WIDTH-1:0] mem [0:DEPTH-1]; reg [ADDR_WIDTH:0] wr_ptr_bin, rd_ptr_bin; reg [ADDR_WIDTH:0] wr_ptr_gray, rd_ptr_gray; reg [ADDR_WIDTH:0] rd_sync1, rd_sync2; reg [ADDR_WIDTH:0] wr_sync1, wr_sync2; // Write pointer always @(posedge wclk or posedge wrst) if (wrst) begin wr_ptr_bin <= 0; wr_ptr_gray <= 0; end else if (wr_en && !full) begin wr_ptr_bin <= wr_ptr_bin + 1; wr_ptr_gray <= (wr_ptr_bin + 1) ^ ((wr_ptr_bin + 1) >> 1); end // Read pointer always @(posedge rclk or posedge rrst) if (rrst) begin rd_ptr_bin <= 0; rd_ptr_gray <= 0; end else if (rd_en && !empty) begin rd_ptr_bin <= rd_ptr_bin + 1; rd_ptr_gray <= (rd_ptr_bin + 1) ^ ((rd_ptr_bin + 1) >> 1); end // 2-FF sync: read pointer → write clock domain always @(posedge wclk or posedge wrst) if (wrst) {rd_sync2, rd_sync1} <= 0; else {rd_sync2, rd_sync1} <= {rd_sync1, rd_ptr_gray}; // 2-FF sync: write pointer → read clock domain always @(posedge rclk or posedge rrst) if (rrst) {wr_sync2, wr_sync1} <= 0; else {wr_sync2, wr_sync1} <= {wr_sync1, wr_ptr_gray}; // Memory always @(posedge wclk) if (wr_en && !full) mem[wr_ptr_bin[ADDR_WIDTH-1:0]] <= din; always @(posedge rclk) if (rd_en && !empty) dout <= mem[rd_ptr_bin[ADDR_WIDTH-1:0]]; // Flags assign full = (wr_ptr_gray == {~rd_sync2[ADDR_WIDTH:ADDR_WIDTH-1], rd_sync2[ADDR_WIDTH-2:0]}); assign empty = (rd_ptr_gray == wr_sync2); endmodule
