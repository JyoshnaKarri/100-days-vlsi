Workflow (simulation & waveform)
.v = Verilog code
.out = compiled output
.vcd = waveform dump
1. Save every file with .v extension
2. In terminal:
iverilog name.v testbench.v
vvp a.out
gtkwave output.vcd
3. For output:
Click on SST
Select all the signals
View waveforms
